# ADR-0006: AI proposes; deterministic code authorizes and decides

Status: Accepted

AI analyzes manifests/OpenAPI/diffs, classifies risk, proposes scenarios/providers/budget allocation, replans and diagnoses. Deterministic components compile mandatory scenarios, approve purchases, verify settlement/replay/idempotency/schema/delivery, aggregate results, and build evidence. AI has no private key, signer, arbitrary HTTP, or direct database-write capability.
